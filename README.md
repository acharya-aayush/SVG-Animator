SVG Animator is a small web project that generates animated SVG loader previews from pasted SVG markup.

Installation
------------

1. Clone the repository.
2. Open `index.html` directly in the browser or serve the files from a simple static server.

Usage
-----

- Paste an SVG into the input area.
- Choose one of the animation variants.
- Adjust stroke weight, dash size, speed, and color.
- Copy the generated HTML or CSS output.
